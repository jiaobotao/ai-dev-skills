# fde-flash-demo

FDE（现场部署工程师/售前）在客户面前 20–30 分钟做出一个**能点、能看、能引发反应**的验证件，帮助客户判断"这个想法值不值得往下做"。

核心信念：**现场交付物不是代码，是客户脑子里的一个判断。** 糙在背面，亮在正面。

- 时间盒：20–30 分钟，五节点
- 默认归宿：用完即弃
- 姊妹技能：[sdd-ai-dev-pipeline](../sdd-ai-dev-pipeline/)（客户要真做时升级）

## 什么时候用

客户现场/工作坊里临时冒出的想法、售前验证、"如果有个功能能 X 会不会很爽"。

不适用：任何要上线、接真实客户数据、进正式代码库、谈交付排期、涉及钱或合规的请求——这些必须走 sdd-ai-dev-pipeline。

## 五节点

| 节点 | 时长 | 产出 |
|---|---|---|
| 1 定靶 | 3–5 分钟 | 一句话假设 + 三幕演示剧本（客户口头确认） |
| 2 竖切 | 10–15 分钟 | 一条贯通纵切面，能真点真跑；MOCK 集中标注 |
| 3 擦亮 | 5–8 分钟（强制保留） | 行业感假数据、高潮亮点瞬间、空态/加载不露怯 |
| 4 自检 | ≤2 分钟 | 金色路径、一键重置、无真实凭据/数据、明示原型 |
| 5 演示收网 | 现场 | 客户亲手操作关键步；三句话写入 FEEDBACK.md |

时间到了没做完的默认动作：**用当前版本演，绝不延期**。宁可删做不完的幕，保住高潮幕。

## 五条微型铁律

1. 不接生产（mock 或只读沙箱）；2. 不用真实敏感数据；3. 可重复演示（一键重置）；4. `flash/<日期-主题>/` 物理隔离，不进正式代码库；5. 开场明示"这是验证原型，数据是演示数据"。

## 自动升级闸门

客户说出"接真实数据/能不能上线/按这个交付"任一类话时，停止承诺现场实现，使用固定回应模板说明正式工程流程，随后转入 sdd-ai-dev-pipeline 的 SOP 1/SOP 12，以验证过的假设为输入重新走四文档。

## 产物

```
flash/2026-09-20-智能排产亮点/
  README.md     # 假设、三幕剧、运行方式、MOCK 清单
  FEEDBACK.md   # 客户原话反应 / 假设是否成立 / 下一步
  app.*         # 原型本体
```

口诀：**一个假设、三幕剧本；竖切一条、造假集中；背面可糙、正面必亮；三十秒检、一键重来；演完收网、要真就转正。**
