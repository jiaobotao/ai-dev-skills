# AI 交付 Skills：SDD 工程流水线 & FDE 现场快闪

一套给 AI 编码助手使用的交付方法论 skill（技能包），把"靠感觉聊天式开发"变成两套有规则、有门禁、有取舍的工作流。两者互为快慢两条轨道：

| Skill | 场景 | 时间尺度 | 交付物 |
|---|---|---|---|
| **[sdd-ai-dev-pipeline](sdd-ai-dev-pipeline/)** | 正式开发：功能、模块、完整项目（企业级 / MVP 双档） | 天～周 | 可上线的代码 + Spec 四文档 + 评审记录 |
| **[fde-flash-demo](fde-flash-demo/)** | 客户现场验证一个想法的演示件 | 20–30 分钟 | 能点能演的原型 + 客户真实反应 |

核心分工：**快闪负责"值不值得做"，流水线负责"稳稳做出来"。** 快闪现场客户一旦说"接真数据/要上线/交付吧"，自动升级到流水线走原型转正（SOP 12），默认不在原型代码上续建。

## 方法论一览

**sdd-ai-dev-pipeline（v2.1）**

- 意图路由 12 条 SOP；企业级 7 专家 / MVP 4 专家两档，Spec 四文档（分析/需求/设计/任务）任何档位不可省。
- 九条铁律：文档不批代码不动、文档是单一事实源、门禁不可跳过、AI 实现阶段不做技术决策、产出归 docs/、阻断必配回归并由原专家复审、mock 全绿≠可交付、断点接续先读文档、前端页面先与用户确认。
- 来自真实项目复盘的硬化机制：状态字段生命周期表 + 控制信号×状态矩阵、流式响应错误路径、"回退即红"回归与变异抽查、假绿反模式清单、T1 环境对账、真实联调门禁（≥3 正常 +1 高风险真实场景）。

**fde-flash-demo**

- 五节点时间盒：定靶（一句话假设 + 三幕剧本）→ 竖切（单纵切面，MOCK 集中）→ 擦亮（强制 5–8 分钟，行业感假数据 + 高潮瞬间）→ 30 秒自检（金色路径/一键重置/无真实凭据/明示原型）→ 演示收网（三句话反馈）。
- 五条微型铁律：不接生产、不用真实敏感数据、可重复演示、flash/ 沙盒物理隔离、明示验证件身份。
- 默认用完即弃；"要真就转正"有固定回应模板与升级闸门。

## 安装

### Claude 桌面版（Cowork，推荐）

将本仓库两个 skill 目录中的 `SKILL.md` 内容通过"保存技能"分别保存为名为 `sdd-ai-dev-pipeline`、`fde-flash-demo` 的技能即可；技能保存在账户中，跨会话、跨设备生效。

### Claude Code（本地手动安装）

```bash
git clone https://github.com/jiaobotao/ai-dev-skills.git ~/ai-dev-skills   # 私有仓库，需你的 GitHub 账号有权限
mkdir -p ~/.claude/skills
cp -R ~/ai-dev-skills/sdd-ai-dev-pipeline ~/.claude/skills/
cp -R ~/ai-dev-skills/fde-flash-demo     ~/.claude/skills/
```

两个目录内的 `SKILL.md` 已带 YAML frontmatter（name/description），Claude Code 启动时会自动识别。升级时重新 `git pull` 并复制覆盖即可。

### 其他支持 SKILL.md 的 AI 编码工具

任何按"目录 + SKILL.md + frontmatter"约定加载技能的工具均可直接使用这两个目录，技术栈无关。

## 快速上手

- 要正式开发一个功能/项目：对助手说"用 sdd 流程做 X"，它会先判定档位（企业级/MVP），依次产出 Spec 四文档，逐份评审后才写代码。
- 在客户现场临时要做一个验证性亮点：说"用快闪流程做 X"，它会先和你对齐一句话假设与三幕剧本，20–30 分钟内交付可演原型。
- 新会话继续一个做了一半的项目：流水线 skill 的**断点接续协议**会强制先读文档、输出"接续确认"，经你确认后再动手。

## 隐私与安全

- 技能本身不含任何客户数据、密钥或真实项目代码。
- 两条工作流均内置安全基线：密钥只走 .env 且不入库、测试零外部调用、前端禁裸 innerHTML、日志禁会话正文；快闪流程额外强制物理隔离与现场数据不留存。
